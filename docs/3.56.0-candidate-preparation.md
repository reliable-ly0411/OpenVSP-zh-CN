## 候选发行说明

`scripts/native_release.py:release_body` 现在可以通过真实上游说明校验器生成 3.56.0 候选正文，
保留完整上游原文、五平台目标和 ABI、校验方法及已知限制。3.56 不套用旧版本族的 rc.2/rc.3
修订历史。默认正文明确标记候选，不能作为原生构建或 GUI 已通过的证据。

官网的 3.56 ARM64 Mac Python 3.11 下载名使用 macOS 15；本仓目标仍为 macOS 14 ARM64，
生成说明明确指出差异。Windows/macOS 目标仍为 Python 3.11，Linux 为 Python 3.12，
NumPy 1.26.4。该目标配置不是本候选的运行成功记录。

可在最终集成源码中只读生成说明预览：

```bash
PYTHONPATH=scripts python3 - <<'PY'
import subprocess
from native_release import release_body
source_sha = subprocess.check_output(['git', 'rev-parse', 'HEAD'], text=True).strip()
print(release_body('3.56.0-zh-CN.rc.1', source_sha, 'reliable-ly0411/OpenVSP-zh-CN'))
PY
```

此命令不调用发布接口，也不创建标签或资产；`rc.1` 是拟用候选标识，最终编号仍须通过
现有标签和同族最新修订门禁。
